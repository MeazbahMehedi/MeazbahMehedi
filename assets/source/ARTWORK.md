# Artwork preparation

The original reference is original-space-banner.png. Source artwork was prepared using the built-in image-generation tool. GIF animation was assembled using FFmpeg and ImageMagick; it contains real multiple frames, not a static image with a .gif extension.

## Prompts

1. Backplate (space-backplate.png): Edit the supplied space banner. Keep the photographic grey moon on the left, craters, starfield, dark navy/black palette and 3:1 framing. Remove only the floating astronaut and the center words HAVE FUN IN CYBERSPACE!, filling those regions with matching space. No additional text, objects or characters.
2. Astronaut cutout (astronaut.png): Extract the full original cream-and-ink floating astronaut on a transparent background. Preserve the same full-body pose, helmet, limbs, proportions, navy outlines and cream fills. No moon, stars, text, background, new objects or cropped limbs.
3. Panda sprite atlas (panda-sprites.png): A 2x2 sheet on true alpha transparency with the same cute black-and-white astronaut panda, cream suit, navy outlines and round helmet. Consistent body scale and camera. Different frames gently wave a raised paw and blink. No floor, lettering, watermark, panels or other objects.

## Animation

- space-banner.gif: 1200×400, 8-second seamless motion loop, 12 frames/second. Gentle astronaut bob/rotation, panda bob, star twinkles, subtle moon-edge glow, and fading original phrase.
- panda.gif: Registered transparent panda sprites with a paw wave and blink. Loops continuously inside its image area.
- Static alternatives are selected by the README's reduced-motion media source where supported.
- The panda is an animated image in the GitHub README. It does not roam over the page or follow the cursor.
